# Interactive Excel Tutorial Platform

🚀 **Learn Excel from Beginner to Advanced with Hands-On Practice**

An interactive web-based Excel learning platform designed to teach data analysis, formulas, and spreadsheet skills through practical exercises with real datasets.

## 🎯 Features

✅ **Interactive Spreadsheet Interface** - Real Excel-like experience
✅ **15 Complete Lessons** - Beginner → Intermediate → Advanced
✅ **Hands-on Exercises** - Practice while you learn
✅ **Real Datasets** - Sales, Finance, Marketing data
✅ **Instant Validation** - Know if your answer is correct immediately
✅ **Progress Tracking** - Track your learning journey
✅ **Challenge Mode** - Test your skills with real-world scenarios
✅ **Beautiful UI** - Modern, responsive design

## 📚 Curriculum Overview

### Level 1: Beginner (Hours 1-3)
1. **Cell Navigation & Selection** - Master basic cell operations
2. **Data Entry & Formatting** - Input and format data professionally
3. **Basic Formulas (SUM)** - Learn the most common formula
4. **AVERAGE & COUNT Functions** - Calculate statistics
5. **Cell References** - Understand absolute vs relative references

### Level 2: Intermediate (Hours 4-8)
6. **IF Function** - Create conditional formulas
7. **VLOOKUP** - Search and return values from tables
8. **Pivot Tables** - Summarize and analyze data
9. **Charts & Visualization** - Create professional charts
10. **Data Validation** - Control data entry

### Level 3: Advanced (Hours 9-15)
11. **INDEX-MATCH** - Advanced lookup techniques
12. **SUMIFS & COUNTIFS** - Conditional aggregation
13. **Array Formulas** - Process multiple values
14. **Dashboard Creation** - Build interactive dashboards
15. **Real-World Project** - Complete analysis project

## 🚀 Quick Start

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/SanjaySamala00/interactive-excel-tutorial.git
cd interactive-excel-tutorial

# Install dependencies
npm install

# Start development server
npm run dev

# Open browser to http://localhost:3000
```

### Build for Production

```bash
npm run build
npm run preview
```
